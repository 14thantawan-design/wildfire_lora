# GPS TX Diagnostic

สเก็ตช์นี้ใช้ตรวจเส้นทาง GPS TX ของ Sensor Node โดยไม่แก้โค้ด `sensor_node` หลัก

- สั่ง GPIO13 เป็น HIGH เพื่อเปิดวงจรจ่ายไฟ GPS
- อ่าน GPS TX ที่ GPIO34 ด้วย 9600 baud
- แสดงผลทาง USB Serial ที่ 115200 baud ทุก 1 วินาที
- ไม่เปิด LoRa, ไม่ใช้ NVS และไม่เข้า deep sleep

การอ่านผล:

- `bytes > 0` และ `nmea > 0` หมายถึง GPS มีไฟและส่งข้อมูล UART/NMEA ได้
- `bytes = 0` หมายถึงต้องตรวจไฟเลี้ยง GPS, สาย TX และ GND ร่วม
- `edges` เพิ่มต่อเนื่องหมายถึงขา TX มีการเปลี่ยนระดับไฟ แม้ตั้ง baud rate ไม่ตรง
- `nmea > 0` แต่ยังไม่มีพิกัดเป็นเรื่องปกติเมื่อทดสอบในอาคาร
