# Baseline Knowledge: Starting from Scratch on Backend, MongoDB, and Dashboard

ผู้เรียนได้ระบุพื้นฐานเริ่มต้นว่ายังไม่เข้าใจส่วนประกอบใดๆ เลย ("ไม่เข้าใจสักอย่างเลย") บทเรียนจึงต้องเริ่มต้นจากโมเดลความคิดเปรียบเทียบในชีวิตประจำวัน (Mental Model & Analogies) การชี้ตำแหน่งไฟล์โฟลเดอร์จริงในโปรเจกต์ และการไล่เส้นทางข้อมูลทีละขั้นแบบเป็นรูปธรรม ก่อนจะลงลึกไปในซอร์สโค้ดระดับฟังก์ชัน
