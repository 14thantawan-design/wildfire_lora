# MongoDB Architecture and Schema Foundation

ผู้เรียนได้ทำความเข้าใจสถาปัตยกรรมและการทำงานของ MongoDB ในโครงงานนี้อย่างละเอียด ได้แก่ บทบาทของ Mongoose, การเชื่อมต่อผ่าน `db.js`, ความแตกต่างระหว่างคอลเลกชันประวัติ (`readings`) และคอลเลกชันสถานะปัจจุบัน (`nodes`), ตลอดจนการใช้ Unique Compound Index ป้องกันข้อมูลซ้ำจากคลื่น LoRa ความเข้าใจนี้เป็นฐานสำคัญในการเรียนรู้ API Routes ในขั้นตอนที่ 2
