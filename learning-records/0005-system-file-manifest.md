# Complete System File Manifest and Architecture Reset

ผู้เรียนต้องการเริ่มทำความเข้าใจใหม่ทั้งหมดจากระดับโครงสร้างไฟล์ (Bird's Eye View) โดยกำหนดเกณฑ์การอธิบายไฟล์อย่างเข้มงวด:
1. ระบุภาษาโปรแกรมที่ใช้ในแต่ละไฟล์
2. ระบุหน้าที่จริงตามข้อเท็จจริงทางเทคนิค (ห้ามเปรียบเทียบ)
3. ระบุผลกระทบหากไฟล์นั้นหายไป (Failure Mode)
4. ระบุเส้นทางการรับข้อมูล (Input) และการส่งต่อข้อมูล (Output / Connected files)
5. ระบุตำแหน่งการแสดงผลจริงบนหน้าเว็บ Dashboard หรือแอปพลิเคชันภายนอก

ครอบคลุมทุกไฟล์ใน `wildfire-backend` และ `wildfire-dashboard` เพื่อให้เห็นภาพการไหลของข้อมูลทั้งระบบจากฮาร์ดแวร์สู่หน้าจอ
