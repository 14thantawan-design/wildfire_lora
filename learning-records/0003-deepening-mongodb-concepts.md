# Deepening MongoDB Understanding: Indexes, Models, Lifecycles, and Edge IoT Constraints

ผู้เรียนได้ระบุจุดที่ติดขัดอย่างละเอียด 6 จุดสำคัญ: ความหมายของ Index และตัวเลขทิศทาง (1/-1), การประกอบ Mongoose Model และจุดที่นำไปเรียกใช้จริง, ความต่างของ unique ระหว่าง snapshot และ history, ความสัมพันธ์ระหว่าง last_seen กับ UI สีเทา (Offline), เหตุผลในการใช้ timestamps อัตโนมัติ, และการเจาะลึกโครงสร้างบรรทัดต่อบรรทัดของ Alert.js และ Command.js ซึ่งเชื่อมโยงโดยตรงกับข้อจำกัดของระบบ IoT พลังงานต่ำ (Deep sleep, LoRa duplicate packets, Telegram notification spam)
