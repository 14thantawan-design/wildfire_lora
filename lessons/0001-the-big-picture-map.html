บทเรียนที่ 1: แผนที่ภาพรวม 3 เสาหลัก
Backend, MongoDB, Dashboard คืออะไร และโค้ดอยู่ที่ไหน?

🎯 เป้าหมายของบทเรียนนี้: ให้คุณมองเห็นภาพรวมทั้งระบบโดยไม่ต้องกลัวโค้ด รู้หน้าที่ของแต่ละตัว และชี้ได้ทันทีว่าแต่ละส่วนซ่อนอยู่ในโฟลเดอร์ไหนของโปรเจกต์นี้

1. เปรียบเทียบกับ "ร้านอาหารอัจฉริยะ"

ถ้าคุณรู้สึกว่าคำศัพท์พวกนี้เข้าใจยาก ให้ลืมเรื่องคอมพิวเตอร์ไปก่อน แล้วนึกถึง ร้านอาหาร:

1. Dashboard (หน้าร้าน)

เปรียบเหมือน โต๊ะอาหารและหน้าจอเมนู ที่ลูกค้าหรือเจ้าหน้าที่มองเห็น สวยงาม สะอาด มีปุ่มให้กด มีแผนที่และกราฟสวยๆ ให้ดู

📁 wildfire-dashboard/

2. Backend (ผู้จัดการ & ห้องครัว)

เปรียบเหมือน ผู้จัดการร้านและบริกร คอยรับของจากคนส่ง ตรวจสอบความถูกต้อง สั่งการ และจัดจานอาหารไปเสิร์ฟที่หน้าร้าน

📁 wildfire-backend/

3. MongoDB (คลังเก็บของ / ตู้เย็น)

เปรียบเหมือน ตู้เซฟหรือคลังวัตถุดิบ เก็บรักษาข้อมูลทุกอย่างไว้ถาวร ไฟดับหรือปิดร้าน ข้อมูลก็ไม่หาย มีระเบียบ ค้นหาง่าย

📁 wildfire-backend/src/models/

2. ข้อมูลเดินทางอย่างไรในระบบนี้?

ลองดูเส้นทางการเดินทางของข้อมูลอุณหภูมิ 1 ค่า จากป่าจนถึงหน้าจอคุณ:

  1. โหนดวัดค่าในป่า: บอร์ด ESP32 อ่านเซนเซอร์ได้ 32°C แล้วยิงคลื่นวิทยุ LoRa ออกไป
  2. Gateway รับคลื่น: แปลงสัญญาณวิทยุเป็นคำสั่งทางอินเทอร์เน็ต (HTTP) แล้วส่งต่อให้ Backend
  3. Backend ตรวจสอบ: ตรวจดูว่าข้อมูลซ้ำไหม ถ้าถูกต้องจะหยิบไปเก็บลงใน MongoDB อย่างปลอดภัย
  4. Dashboard แสดงผล: หน้าเว็บแอบถาม Backend ทุกๆ ไม่กี่วินาทีว่า "มีค่าใหม่ไหม?" แล้วเอาตัวเลข 32°C ไปวาดเป็นกราฟให้เราดู

3. แผนผังไฟล์ในโปรเจกต์ (โค้ดอยู่ตรงไหน?)

ในโฟลเดอร์งานของคุณ มี 2 โฟลเดอร์หลักที่คุณต้องสนใจ:

c:\wildfire_lora\
├── 📂 wildfire-backend/            <-- ฝั่งหลังบ้าน (Node.js + Express)
│   └── 📂 src/
│       ├── 📄 server.js             (จุดเริ่มต้นเซิร์ฟเวอร์ ประตูหน้าบ้าน)
│       ├── 📂 models/               (โครงสร้างข้อมูล MongoDB)
│       │   ├── Node.js              (สถานะโหนดล่าสุด)
│       │   └── Reading.js           (ประวัติการวัดทั้งหมด)
│       └── 📂 routes/               (ประตูเปิดรับส่งข้อมูล API)
│           ├── nodes.js             (แจกข้อมูลโหนด)
│           └── readings.js          (แจกค่าเซนเซอร์ย้อนหลัง)
│
└── 📂 wildfire-dashboard/          <-- ฝั่งหน้าบ้าน (React + Vite)
    └── 📂 src/
        ├── 📄 App.tsx               (หน้าจอหลักของเว็บ)
        ├── 📄 useDashboard.ts       (คนส่งสาร: คอยดึงข้อมูลจาก Backend)
        └── 📂 components/           (ชิ้นส่วนบนหน้าจอ เช่น แผนที่, กราฟ)

4. จุดตรวจสอบความเข้าใจ (Interactive Quiz)

คำถาม: หากคุณต้องการตรวจสอบว่า "ในระบบนี้ เราบันทึกฟิลด์ข้อมูลอะไรบ้างลงในฐานข้อมูล MongoDB (เช่น อุณหภูมิ, ความชื้น)" คุณควรไปเปิดดูโค้ดที่โฟลเดอร์ใด?
