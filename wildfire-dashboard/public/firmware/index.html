ติดตั้งและเพิ่มโหนดในปุ่มเดียว

เฉพาะ LILYGO LoRa32 ESP32 รุ่น 433 MHz และการต่อเซนเซอร์ตามโครงงานนี้ ไม่ใช่เฟิร์มแวร์ Gateway

การติดตั้งเขียนทับโปรแกรมในบอร์ดที่เลือก ตรวจให้แน่ใจว่าเสียบโหนด ไม่ใช่ Gateway และปิด Serial Monitor ก่อน

เสียบบอร์ดผ่าน USB แล้วกดเพิ่ม / คืนโหนดในแถว NODE ที่ต้องการ เว็บจะติดตั้ง FG1 และตั้งรหัสกับกุญแจต่อให้อัตโนมัติ ไม่ต้องติดตั้งแยกจากหน้านี้

เปิดหน้าจัดการโหนดเพื่อติดตั้งและลงทะเบียน
