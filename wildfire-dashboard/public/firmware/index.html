ติดตั้งเฟิร์มแวร์โหนดผ่าน USB

เฉพาะ LILYGO LoRa32 ESP32 รุ่น 433 MHz และการต่อเซนเซอร์ตามโครงงานนี้ ไม่ใช่เฟิร์มแวร์ Gateway

การติดตั้งเขียนทับโปรแกรมในบอร์ดที่เลือก ตรวจให้แน่ใจว่าเสียบโหนด ไม่ใช่ Gateway และปิด Serial Monitor ก่อน

หลังติดตั้ง ปิดหน้านี้ แล้วกลับหน้าจัดการโหนดเพื่อเลือกเลข 1–10 และตั้งค่ากุญแจผ่าน USB

กำลังตรวจไฟล์ติดตั้ง…

เบราว์เซอร์นี้ไม่รองรับ Web Serial ต้องเปิดหน้านี้บน HTTPS หรือ localhost
