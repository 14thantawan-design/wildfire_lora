Wildfire LoRa • Quick Reference Material

สรุปโครงสร้างคอลเลกชัน MongoDB ฉบับพกพา

1. แฟ้มประวัติเซนเซอร์: readings

หน้าที่: เก็บทุกแพ็กเก็ตที่ส่งมาเพื่อวาดกราฟเส้นย้อนหลัง (ห้ามลบ)

ชื่อฟิลด์ชนิดข้อมูลความหมายภาษาคนกฎพิเศษ
node_idStringรหัสประจำตัวของเสา เช่น "NODE01"required ตัดช่องว่างหัวท้าย
session_idNumberรหัสรอบเปิดเครื่อง (เปลี่ยนทุกครั้งที่เปิดใหม่)ใช้คู่กับ seq
seqNumberลำดับรอบการส่ง (1, 2, 3...)ทำ index ค้นหาเร็ว
timestampDateวันเวลาที่ข้อมูลมาถึง Backenddefault: เวลาปัจจุบัน
stateStringสถานะความเสี่ยงที่เฟิร์มแวร์ตัดสินมาenum NORMAL, WATCH, WARNING, SENSOR_FAULT
air_tempNumberอุณหภูมิอากาศ (°C)-
humidityNumberความชื้นสัมพัทธ์ (%RH)-
particle_adcNumberสัญญาณไฟฟ้าควันจาก Sharp GP2Ymin: 0, max: 4095
sensor_healthStringสุขภาพเซนเซอร์ ("OK" หรือ "FAULT")-
rssi / snrNumberความแรงและคุณภาพสัญญาณ LoRa-

2. แฟ้มสถานะปัจจุบัน: nodes

หน้าที่: ป้ายไวท์บอร์ดแสดงสถานะเสาบนแผนที่ (มี 1 แผ่นต่อ 1 เสาเสมอ)

ชื่อฟิลด์ชนิดข้อมูลความหมายภาษาคนกฎพิเศษ
node_idStringรหัสประจำตัวของเสาunique: true ห้ามซ้ำ
lat / lngNumberพิกัดละติจูด และลองจิจูดใช้ปักหมุดบนแผนที่
gps_fixedBooleanชิป GPS ล็อกสัญญาณดาวเทียมได้หรือยังtrue / false
location_sourceStringที่มาของพิกัดenum 'gps' หรือ 'manual'
last_seenDateเวลาล่าสุดที่เสาส่งสัญญาณมาใช้ตรวจจับ Offline / Online
report_interval_secNumberรอบเวลารายงานผล (วินาที)เช่น 300 (5 นาที)

3. แฟ้มแจ้งเตือนไฟป่า: alerts

หน้าที่: ติดตามเหตุการณ์ไฟป่าตั้งแต่เริ่มจนถึงคลี่คลาย ป้องกันการส่งสแปมเข้า Telegram

ชื่อฟิลด์ชนิดข้อมูลความหมายภาษาคนกฎพิเศษ
node_idStringเสาที่พบเหตุการณ์ไฟป่า-
levelStringระดับความเสี่ยงปัจจุบันของเหตุการณ์enum WATCH, WARNING, SENSOR_FAULT
activeBooleanเหตุการณ์ยังดำเนินอยู่หรือไม่true = ยังไม่ดับ, false = ดับแล้ว
started_at / ended_atDateเวลาเริ่มเกิดเหตุ และเวลาที่สถานะกลับสู่ NORMAL-
telegram_notified_levelStringระดับล่าสุดที่เคยส่งแจ้งเตือน Telegram ไปแล้วกันส่งซ้ำถ้าระดับไม่เปลี่ยน

4. แฟ้มคิวคำสั่งโหนด: commands

หน้าที่: เก็บคำสั่งรอดาวน์ลิงก์ตอนเสาตื่น และทำลายตัวเองอัตโนมัติเมื่อหมดอายุ

ชื่อฟิลด์ชนิดข้อมูลความหมายภาษาคนกฎพิเศษ
command_idStringรหัสกำกับคำสั่งแบบไม่ซ้ำunique: true
commandStringชนิดคำสั่งenum 'gps_reacquire', 'gps_manual'
statusStringสถานะคำสั่ง'pending', 'sent', 'acknowledged', 'rejected'
expires_atDateเวลาหมดอายุของคำสั่งTTL Index ลบตัวเองทิ้งเมื่อถึงเวลา
